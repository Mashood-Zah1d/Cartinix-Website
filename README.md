# Cartinix Website

A full-stack eCommerce web application built with **Node.js, Express.js, PostgreSQL, and JavaScript**.

## Overview

Cartinix is an eCommerce platform that allows users to browse products, manage their accounts, add products to their cart, and place orders.

The application also includes email-based functionality for account recovery and order-related communication.

## Features

* User registration and authentication
* Product browsing
* Shopping cart functionality
* Order placement
* Password reset functionality
* Email notifications
* PostgreSQL database integration
* REST API backend
* File/image upload handling

## Tech Stack

**Backend**

* Node.js
* Express.js

**Database**

* PostgreSQL

**Frontend**

* HTML
* CSS
* JavaScript

**Other Tools & Libraries**

* Nodemailer
* Multer
* bcrypt
* REST APIs
